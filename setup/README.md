# Setup new Desktop

## Common Steps (Required)

### Set up dotfiles

Follow the [chezmoi setup](../README.md#dotfiles-arrangement), then change
to the repository root with `cd ~/.local/share/chezmoi`.

### Install fonts

Run `./fonts/install` from the *dotfiles* repo root.
